# 목차

`notes/`의 정리본과 `queries/`의 저장한 답 목록이다. 에이전트가 정리하거나 답을 저장할 때마다 갱신한다.

## 정리본
- [[개념 - 하네스와 CLI 에이전트]] — 채팅창 AI와 내 컴퓨터 폴더에서 직접 일하는 CLI 에이전트(하네스)의 차이와 "AI 신입사원" 5대 개념 비유
- [[개념 - MCP와 스킬과 플러그인]] — 사내 시스템 출입증(MCP)과 업무 매뉴얼(`SKILL.md`), 그리고 도구를 연결하는 3가지 실전 방식(커넥터·로컬 MCP·심링크)
- [[개념 - LLM 위키와 세컨드 브레인]] — 원본(`inbox/`)은 보존하고 AI가 정리본(`notes/`)을 관리하는 세컨드 브레인 원리와 소모임 공동 활용·업데이트 규칙
- [[도구 - Claude Code와 Codex와 Antigravity]] — AI 구독별 주력 하네스 3종의 특징, 설치 명령어, 초기 트러블슈팅
- [[도구 - 헤르메스 에이전트와 OpenClaw와 연구용 AI]] — 컴퓨터의 하네스를 총괄·메신저로 잇는 헤르메스 에이전트, OpenClaw, 논문·연구 분석용 AI 3종(Liner·ResearchRabbit·SciSpace)
- [[우리자산 - JAIX kit와 제주연구원 업무 스킬]] — 제주연구원 업무 자동화를 위해 만든 `JAIX kit`, 그룹웨어(`ji-gw-ai`), 메일(`mail-skill`), 업무일지(`calendar-worklog`), HWP 편집(`hwp-agent`), `korea-rio-mcp` 도감
- [[운영 - 소모임 히스토리와 하고 싶은 주제]] — 2025년 12월부터 2026년 11월까지의 소모임 진화 흐름, 예산·기자재 논의, 앞으로 하고 싶은 주제(GitHub 입문 등)
