# 우리 목적

> 제주연구원 인공지능연구회 소모임 구성원들이 함께 쌓고 꺼내 쓰는 세컨드 브레인의 기준입니다. 에이전트는 일하기 전에 이 문서를 먼저 읽습니다.

## 우리는
- 제주연구원 구성원들이 매주(또는 격주) 목요일에 모여 인공지능 도구와 에이전트(하네스)를 직접 설치하고 연구·행정 업무에 적용해 보는 사내 인공지능연구회 소모임이다.
- 코딩이나 Git 협업이 아직 낯선 구성원도 한국어 대화만으로 에이전트를 다루고 동료가 만든 스킬을 가져다 쓸 수 있게 돕는 것을 지향한다.

## 이 폴더에 모으는 이유
- **소모임 지식 백과사전**: 매 회차 배운 핵심 개념(하네스, CLI, MCP, 스킬, 플러그인, AGENTS.md, LLM 위키)과 도구 사용법을 날짜별 폴더 속에 묻어두지 않고 서로 연결된 정리본(`notes/`)으로 쌓아, 언제든 에이전트에게 물어보고 바로 따라 하기 위해.
- **제주연구원 맞춤형 업무 자동화 확산**: 구성원이 만든 사내·공개 자산(`JAIX kit`, `ji-gw-ai`, `mail-skill`, `calendar-worklog`, `hwp-agent`, `korea-rio-mcp`, `hermes-slackbot` 등)의 역할과 설치·활용법을 한곳에서 찾아 내 업무(HWP 문서, 그룹웨어 결재·일정, 메일, 슬랙, 데이터 분석, 문헌 조사)에 재활용하기 위해.
- **다음 소모임 주제와 질문 이어가기**: 모임 중에 나온 미해결 질문이나 해보고 싶은 과제를 휘발시키지 않고 기록해 다음 회차 실습 재료로 삼기 위해.

## 지금 궁금한 것 (소모임 공동 관심사)
- 새로 합류하거나 지난 모임에 빠진 구성원이 우리 소모임 도구(하네스 3종, MCP, 스킬, JAIX kit)를 가장 쉽게 따라 잡으려면 어떤 순서로 무엇을 해봐야 하는가?
- 하네스로 컴퓨터에서 하던 작업을 모바일이나 메신저(헤르메스 에이전트·슬랙봇)에서 자연스럽게 이어하려면 어떻게 구성해야 하는가?
- Git과 GitHub(클론·풀·브랜치·커밋·PR·이슈)가 처음인 구성원들이 충돌 없이 이 위키를 최신 상태로 받아 쓰고 자기 노하우를 보태려면 어떻게 해야 하는가?
