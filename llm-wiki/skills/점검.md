# 점검 스킬 (lint)

`notes/`를 점검해 고칠 거리와 다음 소모임에서 다룰 만한 주제를 목록으로 보여준다.

## 순서
1. `우리 목적.md`, `index.md`, `notes/`를 읽는다. 필요하면 `inbox/` 원본도 연다.
2. 아래를 찾아 목록으로 보여준다. **이 단계에서는 파일을 고치지 않는다.**
   - 서로 어긋나는 내용 (또는 예전 회차 기준이라 현재 도구 상태와 달라진 내용)
   - 다른 노트와 연결이 하나도 없는 고아 노트
   - 여러 번 언급되지만 아직 독립 노트가 없는 중요한 개념·도구
   - `index.md`에 빠진 노트, 또는 없는 노트를 가리키는 항목
   - 원본 링크(`원본:`)가 없는 정리본
   - 아직 해결되지 않아 다음 소모임 실습 주제로 삼으면 좋을 질문 1~3개
3. 내가 고칠 항목을 고르면 계획을 보여주고, 확인을 받은 뒤 고친다.

## 지킬 것
- `inbox/`는 절대 수정·이동·삭제하지 않는다.
