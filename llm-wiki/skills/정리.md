# 정리 스킬 (ingest)

`inbox/`의 원본 메모를 읽고 `notes/`에 정리본을 만들며 `index.md`를 갱신한다.

## 순서
1. `우리 목적.md`와 `index.md`를 읽는다.
2. 아직 정리하지 않은 `inbox/` 메모를 찾는다. 어떤 정리본에도 원본 링크로 걸려 있지 않은 메모가 대상이다.
   - "다시 정리해줘"라고 하면 `inbox/` 메모 전체를 다시 본다.
   - 내가 상위 폴더(`../study-group/` 또는 `../meetings/`)의 특정 회차 자료를 가리키며 정리해 달라고 하면, 그 자료의 핵심 내용을 먼저 `inbox/`에 요약 원본 메모로 남기거나 참조하여 함께 정리한다.
3. 계획을 보여준다. 만들거나 고칠 노트 이름, 각 노트에 들어갈 원본 메모, 그렇게 묶은 이유. **내 확인을 받기 전에는 파일을 만들거나 고치지 않는다.**
4. 확인을 받으면 정리본을 만들거나 고친다.
5. `index.md`를 갱신한다.
6. 만들고 고친 파일 목록을 보여준다.

## 정리본 형식
- 맨 위에 `원본: [[inbox/파일명]]`을 적는다. 여러 원본을 합쳤으면 모두 적는다.
- 그 아래 한 줄 요약을 쓴다.
- 원본에 없는 내용은 쓰지 않는다.
- 예전 회차 기록과 최근 회차 기록이 서로 달라졌거나 도구가 업데이트된 경우에는 추측해서 덮어쓰지 않고, 언제 어떻게 바뀌었는지 두 시점의 내용을 함께 적는다.
- 다른 노트와 내용이 실제로 이어질 때만 `[[노트 이름]]`으로 링크하고, 옆에 왜 연결했는지 한 줄을 쓴다.

## index.md 형식
- "정리본" 아래에 노트마다 `- [[노트 이름]] — 한 줄 설명`을 적는다. "저장한 답" 부분은 건드리지 않는다.

## 지킬 것
- `inbox/`의 기존 파일은 절대 수정·이동·삭제하지 않는다.
- 공개 저장소 보안 규칙을 지킨다. 전화번호·이메일·계좌·비밀번호·API 키·내부망 IP·영수증·대외비 내용은 정리본에 옮기지 않는다.
