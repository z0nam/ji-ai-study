# 제주연구원 인공지능연구회 소모임 LLM 위키 (`llm-wiki`)

11/20 「LLM 위키로 시작하는 세컨드 브레인」 실습에서 다룬 **심플 버전 구조**를 그대로 활용해, 우리 소모임의 운영 기록과 배운 개념·도구·사내 스킬을 함께 쌓고 물어보는 **소모임 공동 세컨드 브레인**입니다.

Git이나 코딩에 익숙하지 않은 구성원도 **에이전트에게 한국어 문장 하나만 복사해 붙여넣으면** 내 컴퓨터에 설치하고, 최신 상태로 업데이트하고, 궁금한 내용을 질문할 수 있도록 설계되어 있습니다.

---

## 1. 처음 한 번 · 내 컴퓨터에 설치하기 (1분 완성)

터미널 명령어를 외울 필요가 없습니다. 사용하시는 에이전트 앱(**Claude 데스크톱 앱 Code 탭**, **ChatGPT 데스크톱 앱 Codex**, 또는 **Antigravity**)을 아무 폴더에서나 열고 아래 문장을 그대로 복사해 붙여넣으세요.

```text
내 홈 폴더 바로 아래에 제주연구원 인공지능연구회 저장소(https://github.com/z0nam/ji-ai-study.git)를 클론해줘. 이미 폴더가 있으면 최신 상태로 업데이트해줘. 다 되면:
1) Obsidian에서 보관함으로 열어야 할 정확한 llm-wiki 폴더 경로
2) 에이전트에서 열어야 할 정확한 llm-wiki 폴더 경로
3) 최근 소모임 주제 3개
를 표로 쉽게 알려줘.
```

### 설치가 끝나면 두 가지를 엽니다
1. **Obsidian 열기**: 첫 화면(또는 왼쪽 아래 금고 아이콘) → **보관함 폴더 열기(Open folder as vault)** → 방금 받은 `ji-ai-study` 안의 **`llm-wiki`** 폴더를 선택합니다.
2. **에이전트 작업 폴더 열기**: 에이전트(Claude Code · Codex · Antigravity)에서도 똑같이 **`ji-ai-study/llm-wiki`** 폴더를 엽니다. *(상위 폴더가 아니라 `llm-wiki` 폴더를 열어야 5개 스킬이 자동으로 인식됩니다.)*
3. **첫 확인 문장 보내기**:
   ```text
   이 폴더에서 쓸 수 있는 스킬을 알려줘.
   ```
   → **업데이트 · 정리 · 질문 · 점검 · 리서치** 다섯 가지 스킬이 나오면 준비 끝입니다!

---

## 2. 매주 쓸 때 · 최신 상태로 유지하기 (`업데이트 스킬`)

소모임이 끝날 때마다 새로운 개념 노트와 실습 기록이 위키에 추가됩니다.
이 폴더의 에이전트는 대화를 시작할 때 **자동으로 새 업데이트가 있는지 확인**해 알려주며, 언제든 아래 한 마디만 보내면 최신 상태로 맞춰 줍니다.

```text
업데이트해줘.
```

- **내가 파일을 건드려 놓았어도 걱정 마세요**: 내 컴퓨터에서 연습 삼아 고친 파일이 있어도 에러를 내거나 날리지 않고, `내연습/백업/`에 안전하게 따로 보관한 뒤 최신 소모임 위키로 맞춰 줍니다.
- 업데이트가 끝나면 **지난번 이후 새로 추가된 소모임 내용 3줄 요약**을 바로 브리핑해 줍니다.

## 3. 들어 있는 폴더와 파일

| 이름 | 역할 | 누가 관리하나 |
|---|---|---|
| `inbox/` | **원본 메모**. 회차별 소모임 기록, 핸드아웃 요약, 구성원이 공유한 노하우가 들어 있습니다. | 원본 보존 (에이전트는 읽기만 함) |
| `notes/` | **정리본(위키)**. 개념·도구·우리 연구원 자산·운영 현황을 주제별로 연결해 정리한 노트입니다. | 에이전트가 `정리 스킬`로 작성·갱신 |
| `queries/` | **저장한 답**. 모임 중 물어보고 "저장해줘"라고 한 비교표·가이드·초안이 쌓입니다. | 에이전트가 `질문 스킬`로 저장 |
| `index.md` | `notes/`와 `queries/`의 전체 목차입니다. | 에이전트가 자동 갱신 |
| `우리 목적.md` | 우리 소모임이 왜 이 위키를 모으고 어디에 쓰는지 적은 기준 문서입니다. | 에이전트가 작업 전 먼저 읽음 |
| `skills/` | 에이전트가 일하는 5가지 작업 설명서(`업데이트·정리·질문·점검·리서치`)입니다. | 직접 열어 읽고 규칙 추가 가능 |
| `요청 모음.md` | 복사해서 바로 붙여넣는 상황별 요청 문장 모음입니다. | 구성원 참고용 |
| `내연습/` | 내 컴퓨터에서만 자유롭게 연습하거나 비공개 개인 메모를 넣어 보는 공간입니다. | Git 추적 제외 (충돌 걱정 없음) |

## 4. 우리 소모임 구성원들이 함께 쓰는 3단계 방법

### 🟢 1단계 (누구나 · 상시): 업데이트 받고 소모임 지식 물어보기
- 모임에 빠졌거나 예전에 배운 도구 설치법이 헷갈릴 때:
  - `"업데이트해줘."`
  - `"질문 스킬로 답해줘. 우리 소모임에서 배운 MCP랑 스킬이 뭐가 다른지 비유로 쉽게 설명해줘."`
  - `"질문 스킬로 답해줘. JAIX kit에는 어떤 기능들이 들어 있고 어떻게 써?"`
- 내 개인 업무 메모로 연습해 보고 싶을 때는 **`내연습/`** 폴더에 넣고 마음껏 실험하세요. GitHub으로 올라가지도 않고 다음 주 업데이트할 때 충돌도 나지 않습니다.

### 🟡 2단계 (소모임 시간): 다 같이 새 회차 정리하고 받아보기
- 목요일 소모임 마지막 10분에 그날 배운 내용이나 슬랙 캔버스 메모를 `inbox/`에 새 파일로 넣고, 대표 화면에서 `"정리 스킬로 새 메모만 정리해줘"`를 실행해 GitHub에 올립니다.
- 참석한 구성원들은 각자 노트북에서 **`"업데이트해줘"`** 한 마디만 치면 내 Obsidian 그래프 뷰에 오늘 배운 개념 노트가 즉시 연결되어 나타납니다.

### 🔵 3단계 (한 걸음 더): 내 활용 노하우 한 장 보태기
- 내가 써본 프롬프트나 스킬 활용 팁을 동호회에 공유하고 싶다면 `inbox/날짜-내이름-주제.md` 파일 하나만 추가합니다. (기존 파일을 고치지 않고 새 파일만 넣으므로 다른 사람과 절대 충돌하지 않습니다.)

- 비공개 개인 메모로 테스트해 보고 싶을 때는 공용 `inbox/` 대신 **`내연습/`** 폴더를 이용해 주세요.
