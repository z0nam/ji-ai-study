## 1. 외부 도구를 에이전트에 붙이는 세 가지 연결 방식
| 방식 | 붙이는 법 | 대표 실습 대상 |
|---|---|---|
| **① 커넥터(클릭)** | `claude.ai` Settings → Connectors에서 스위치 ON (또는 `/plugin install`) → Claude Code와 자동 공유 | Slack · monday.com · Google Calendar |
| **② 로컬 MCP 서버** | 프로그램을 stdio로 감싸 `claude mcp add` (또는 Codex `config.toml`, Gemini `settings.json`)에 등록 | `korea-rio-mcp` (지역 경제파급효과 계산), `hwpx-mcp` |
| **③ SKILL.md + 심링크** | 실행 가능한 CLI 도구를 `PATH`(`~/.local/bin`)에 두고, 사용설명서(`SKILL.md`) 한 장을 에이전트 스킬 폴더에 심링크 | `mail-skill`, `ji-gw-ai`, `messages-cli`, `contacts-cli`, 나만의 스킬 |

## 2. 왜 심링크(Symlink)와 플랫폼 프리 설계를 쓰는가
- 원본 `SKILL.md` 한 곳만 고치면 `~/.claude/skills/`와 `~/.codex/skills/` 양쪽에 즉시 반영되어 여러 에이전트를 동시에 지원할 수 있다.
- 로컬 stdio MCP 서버 하나(`korea-rio-mcp` 등)를 만들면 Claude Code, Codex, Gemini/Antigravity 세 플랫폼에서 모두 똑같이 꽂아 쓸 수 있다.
  - 설치: `uv tool install git+https://github.com/z0nam/korea-rio-mcp`
  - Claude 등록: `claude mcp add korea-rio -- korea-rio-mcp`
  - 활용 프롬프트: `"서귀포에 100억 투자하면 생산유발효과가 얼마야?"`

## 3. 사내·공개 실습 자산과 안전 수칙
- **그룹웨어(`ji-gw-ai`, 명령어 `gw`)**: 레거시 그룹웨어를 CLI+어댑터로 감싸고 `SKILL.md`로 노출한 사내 자산. 결재함 읽기(`gw approvals`), 결재 본문 Slack DM 전송(`gw download <wscNo> --dm`), 출근기록 대조 후 지참 기안(`gw late-check --draft`), 과제 예산 잔액 조회(`gw budget`)를 수행한다. **상신 같은 위험 행위는 직전에 멈추고 사람이 확인한다.**
- **메일(`z0nam/mail-skill`, 명령어 `mailskill`)**: Himalaya 엔진을 어댑터 뒤에 숨긴 공개 메일 CLI·스킬. `accounts`, `list`, `search`, `read`, `reply`(초안만 작성, 발송은 승인 후) 5개 동사로 동작하며 비밀번호는 age로 암호화한다.
- **슬랙·먼데이 관리(`ji-slack-admin`, `ji-monday-admin`)**: 회사 슬랙 채널ID·유저UID를 로컬 캐시해 조회하거나 먼데이 보드를 연결한다.
- **안전 수칙**: 토큰·비밀번호는 코드에 하드코딩하지 않고 `.env`나 암호화 저장소로 분리하며, 삭제·상신·발송 등 변경 작업은 반드시 사람의 승인을 거친다.
