## 1. 채팅창 AI와 에이전트의 차이
- **채팅창 AI**: 우리 컴퓨터 밖에 있어서 질문에 답을 말로만 해준다(예: "pdf 변환은 이런 코드를 쓰시면 됩니다").
- **CLI 에이전트(하네스)**: 내가 있는 폴더 안에서 직접 파일을 읽고, 고치고, 프로그램을 실행하고, 에러가 나면 고쳐서 결과물로 끝낸다(예: 폴더 안의 hwp 파일 3개를 직접 pdf로 변환해 놓음).
- 파일 수정이나 명령 실행 전에는 사람의 **승인**을 물어보므로 허락 없이는 움직이지 않는다. 단, 처음 연습할 때는 중요한 보고서 폴더가 아닌 빈 폴더에서 실습한다.

## 2. "AI 신입사원" 비유로 끝내는 5대 핵심 개념
똑똑하지만 우리 회사 사정을 모르는 신입사원(= AI 에이전트)이 일 잘하게 만들려면 다섯 가지가 필요하다.

| 필요한 것 | AI 세계의 이름 | 한 줄 정의 |
|---|---|---|
| 대화할 창구 | **CLI** | 신입사원과 한국어로 이야기하는 터미널 창 (`claude`, `codex` 등) |
| 사내 시스템 출입증 | **MCP** | 그룹웨어·슬랙·한글문서 등 외부 시스템에 접속하는 표준 연결 규격 ("AI용 USB-C 단자") |
| 업무 매뉴얼 | **스킬(Skill)** | `"이 일은 이렇게 처리해"`라고 작업 절차·요령·주의사항을 적어둔 매뉴얼 폴더(`SKILL.md`) |
| 매뉴얼+출입증 세트 상자 | **플러그인(Plugin)** | 스킬·명령어·MCP 연결 설정을 한 번에 설치하도록 묶어 배포하는 꾸러미 ("신입사원 온보딩 키트") |
| 팀 규칙 게시판 | **CLAUDE.md / AGENTS.md** | 프로젝트 폴더 맨 위에 두어 AI가 대화 시작할 때마다 자동으로 읽는 상시 기본 규칙 |

## 3. 구독별 에이전트 도구 3종 배정 및 설치 명령
- **Claude 유료 구독(Pro 이상)** → **Claude Code** (터미널 기반)
  - Mac: `curl -fsSL https://claude.ai/install.sh | bash`
  - Windows PowerShell: `irm https://claude.ai/install.ps1 | iex`
- **ChatGPT 유료 구독(Plus 이상)** → **Codex** (터미널/앱 기반)
  - Mac: `curl -fsSL https://chatgpt.com/codex/install.sh | sh`
  - Windows PowerShell: `powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"`
- **Gemini 또는 무구독** → **Antigravity** (VS Code 스타일 앱, 구글 계정만 있으면 프리뷰 무료)
  - `antigravity.google/download`에서 OS에 맞게 다운로드 및 설치.

## 4. MCP와 스킬이 조합되는 대표 흐름
- `"이번 주 업무일지 작성해서 그룹웨어에 올리고, 요약을 소모임 채널에 공유해줘"`라고 한 문장으로 지시하면:
  1. `AGENTS.md`의 기본 규칙 확인
  2. `ji-gw-ai`(출입증/도구)로 그룹웨어 접속해 이번 주 일정 조회
  3. `calendar-worklog`(스킬 매뉴얼) 양식대로 업무일지 초안 작성
  4. `hwp-agent` + `hwpx-mcp`로 기관 양식 hwpx 생성
  5. 그룹웨어 등록 및 `Slack MCP`로 소모임 채널에 요약 공유
