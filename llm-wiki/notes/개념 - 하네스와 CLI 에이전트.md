채팅창 AI가 컴퓨터 밖에서 말로만 답하는 것과 달리, CLI 에이전트(하네스)는 내 작업 폴더 안에서 파일을 읽고 고치며 프로그램을 실행해 일을 끝내는 AI 동료다.

## 1. 채팅창 AI vs CLI 에이전트(하네스)
- 우리 소모임에서는 Claude Code, Codex, Antigravity처럼 모델을 감싸 도구를 쓰게 해주는 에이전트 실행 환경을 **하네스(Harness)**(국내에서는 흔히 "AI 에이전트")라고 부른다.
- **채팅창 AI**: 우리 컴퓨터 파일이나 화면을 직접 볼 수 없어 `"pdf 변환은 이런 코드를 쓰세요"`처럼 말로만 답한다.
- **CLI 에이전트(하네스)**: 지금 내가 열어 둔 폴더 안에서 파일을 읽고, 코드를 짜서 실행하고, 에러가 나면 스스로 고쳐 결과 파일을 폴더에 만들어 놓는다(예: `"이 폴더의 hwp 파일 3개를 전부 pdf로 바꿔줘"`).
- **안전장치**: 파일 수정이나 명령 실행 전에는 반드시 사람의 **승인**을 구하므로 허락 없이 마음대로 움직이지 않는다. 단, 처음 연습할 때는 중요한 보고서 폴더가 아닌 빈 폴더에서 실습한다.

## 2. "AI 신입사원" 비유로 보는 5대 구성 요소
똑똑하지만 우리 연구원 사정을 하나도 모르는 신입사원(= 에이전트)이 일을 잘하게 만들려면 다섯 가지가 필요하다.

| 비유 | 개념 이름 | 역할 한 줄 요약 |
|---|---|---|
| 대화할 창구 | **CLI** | 신입사원과 한국어로 대화하는 터미널 창 (`claude`, `codex` 등) |
| 사내 시스템 출입증 | **MCP** | 그룹웨어·슬랙·한글문서 등 외부 시스템에 접속하는 표준 연결 규격 |
| 업무 매뉴얼 | **스킬(Skill)** | `"이 일은 이렇게 처리해"`라고 작업 절차와 주의사항을 적은 매뉴얼 폴더(`SKILL.md`) |
| 매뉴얼+출입증 세트 상자 | **플러그인(Plugin)** | 스킬·명령어·MCP 연결을 한 번에 설치하도록 묶은 온보딩 키트 |
| 팀 규칙 게시판 | **AGENTS.md / CLAUDE.md** | 폴더 맨 위에 두어 대화 시작 때마다 AI가 자동으로 읽는 상시 기본 규칙 |
