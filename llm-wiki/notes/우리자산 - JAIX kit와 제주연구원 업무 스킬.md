우리 소모임에서는 제주연구원의 실제 업무(그룹웨어 결재·일정, 회사 메일, 슬랙, HWP 문서 편집, 지역산업연관분석)를 에이전트로 자동화하기 위해 직접 만든 MCP·스킬 자산들을 `JAIX kit`로 묶어 활용하고 있다.

## 1. JAIX kit (제주연구원 AI 업무 종합 키트)
- **2026-11-05 소모임**에서 소개 및 설치 실습을 진행한 종합 업무 스킬 묶음이다.
- 개별적으로 흩어져 있던 사내·공개 스킬(HWP 문서 편집, 결재 준비·확인, 회의실 예약, 회사 메일 확인, 캘린더 업무일지, 헤르메스 에이전트 활용)을 한 번에 설치하고 쓸 수 있도록 모은 온보딩 키트다.

## 2. 제주연구원 주요 스킬·MCP 자산 도감

| 자산 이름 (저장소) | 공개 여부 | 연결 방식 | 주요 기능 및 활용 예시 |
|---|---|---|---|
| **`ji-gw-ai`** (`gw`) | 사내 전용 | CLI+어댑터 + `SKILL.md` | • 그룹웨어 결재함 읽기(`gw approvals`), 결재문서 다운로드 후 Slack DM 알림(`gw download <wscNo> --dm`)<br>• 출근기록 대조 지참 기안(`gw late-check --draft`), 과제 예산 잔액 조회(`gw budget`), 일정·회의실 예약<br>• **안전장치**: 상신 등 위험 행위는 직전에 멈추고 사람이 확인 |
| **`mail-skill`** (`mailskill`) | 공개 (`z0nam/mail-skill`) | CLI(Himalaya 어댑터) + `SKILL.md` | • 회사·개인 메일 통합 조회(`accounts`, `list`, `search`, `read`) 및 답장 초안 작성(`reply`, 발송은 승인 후)<br>• 비밀번호는 평문 없이 `age`로 암호화 보관 |
| **`calendar-worklog`** | 공개 (`z0nam/calendar-worklog`) | 플러그인 / `SKILL.md` | • 그룹웨어·캘린더·슬랙 활동을 종합해 일별·주간 업무일지를 자동 정리하고 슬랙 연동 |
| **`hwp-agent` & `hwpx-mcp`** | 공개 (`z0nam/hwp-agent`) | CLI / 로컬 MCP + `SKILL.md` | • 기관 표준 문서 양식인 한글(`.hwp`, `.hwpx`) 문서를 깨짐 없이 읽고 표·본문을 채워 편집 (이중화 님 `hwpx-mcp` 가이드와 연결) |
| **`korea-rio-mcp`** | 공개 (`z0nam/korea-rio-mcp`) | 로컬 stdio MCP 서버 | • 한국은행 지역산업연관표 기반 지역 경제파급효과(생산·부가가치·취업유발효과) 계산<br>• 예: `"서귀포에 100억 투자하면 생산유발효과가 얼마야?"` |
| **`hermes-slackbot`** | 공개 (`z0nam/hermes-slackbot`) | 헤르메스 에이전트 슬랙봇 | • 개인 또는 소모임의 헤르메스 에이전트를 슬랙 채널·DM과 연결해 메신저에서 업무 지시 |
| **`ji-slack-admin` / `ji-monday-admin`** | 사내 전용 | CLI / MCP 설정 | • 사내 슬랙 채널·사용자 디렉터리 로컬 캐시 조회 및 monday.com 보드 연동 |

## 3. 사내 배포 및 보안 원칙 (`ji-deploy-standards`)
1. **플랫폼 프리(Platform-free)**: Claude Code, Codex, Gemini/Antigravity 어느 도구를 쓰든 똑같이 동작하도록 표준 stdio MCP 또는 `SKILL.md` + 심링크 구조로 만든다.
2. **안전 수칙**: 토큰·비밀번호·내부망 IP는 코드나 공개 저장소에 절대 하드코딩하지 않고 `.env` 또는 암호화 도구로 분리하며, 삭제·상신·발송은 반드시 사용자 승인을 거친다.
