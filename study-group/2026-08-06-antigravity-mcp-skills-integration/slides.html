핵심 개념 재정립

MCP vs Skill: 무엇이 다른가요?

MCP (Model Context Protocol)

"사내 시스템 실시간 API 출입증"

  • 클라이언트-서버 구조로 표준 프로토콜 통신
  • 슬랙, 먼데이, 메일 서버의 최신 데이터를 실시간으로 가져옴
  • 에이전트가 호출 가능한 Tool 함수 제공

Skill (스킬)

"AI 전용 업무 매뉴얼 (`SKILL.md`)"

  • CLI 도구나 셸 스크립트 실행 방법과 규칙 정의
  • `gw approvals`, `hwp2pdf` 등 내 컴퓨터 명령 실행
  • 간단한 Markdown 파일 수정으로 누구나 작성 가능

실습 1단계: Clone & Install

GitHub 자산 내 노트북으로 가져오기

터미널(Terminal)을 열고 아래 명령어를 순서대로 실행하세요:

Bash - Repository Clone & Set Up 
# 1. 개발 작업 폴더 이동
mkdir -p ~/dev && cd ~/dev

# 2. 그룹웨어 CLI 클론 및 uv 설치
git clone https://github.com/z0nam/ji-gw-ai.git
cd ji-gw-ai && uv sync && uv tool install --editable . && cd ..

# 3. 슬랙, 먼데이, 메일 스킬 클론
git clone https://github.com/z0nam/ji-slack-admin.git
git clone https://github.com/z0nam/ji-monday-admin.git
git clone https://github.com/z0nam/mail-skill.git
실습 2단계: 자격증명 (.env)

안전하게 인증 정보 설정하기

비밀번호, 토큰, API 키는 코드에 직접 적으면 절대로 안 됩니다.
각 프로젝트의 .env.example을 복사하여 .env 파일로 만듭니다.

.env 설정 명령어 
# 예: ji-gw-ai 설정
cd ~/dev/ji-gw-ai
cp .env.example .env

# .env 수정 (본인 GW 아이디/비밀번호)
nano .env  # 또는 VS Code로 편집

보안 필수 규칙

  • .env는 깃허브 금지 (이미 .gitignore 등록됨)
  • 에이전트에게 비밀번호를 직접 말하지 말고 .env로 전달
  • 실습 시 승인형 모드 사용 권장
서비스 연동 ①

메일 (Mail Skill) 직접 써보기

메일함 검색 및 요약, 답장 드래프트 작성을 AI 에이전트에게 요청해보세요.

에이전트에 입력할 프롬프트 예시

"최근 받은 메일 중에서 '소모임' 관련 메일 찾아서 핵심 내용을 3줄로 요약해줘."

내부 동작 방식

mail 스킬이 실행되어 로컬 메일 DB 또는 IMAP/Gmail API를 조회하고 읽지 않은 메일의 제목, 발신자, 본문을 파싱하여 에이전트에게 전달합니다.

서비스 연동 ②

슬랙 (Slack MCP) 직접 써보기

claude.ai Slack Connector 또는 Slack MCP로 사내 채널을 읽고 작성합니다.

에이전트에 입력할 프롬프트 예시

"오늘 #인공지능연구회 채널에 올라온 주요 스레드 메시지를 다 정리해줘."

채널 읽기 & 검색

슬랙 채널의 주고받은 대화 내용을 실시간으로 파악하여 미팅 안건이나 공유 자료를 요약합니다.

공지 작성 (승인 필수)

에이전트가 작성한 공지문을 채널에 올리기 직전, 사용자에게 최종 확인 승인(Prompt)을 요청합니다.

서비스 연동 ③

먼데이 (Monday Admin) 연동하기

먼데이(Monday.com) API를 연동하여 프로젝트 보드 항목과 지연 태스크를 점검합니다.

에이전트에 입력할 프롬프트 예시

"이번 주 '7월 연구과제' 보드에서 '진행 중'인 태스크 목록과 담당자를 확인해줘."

.env 설정 체크 (ji-monday-admin)
MONDAY_API_TOKEN="your_monday_api_v2_token_here"
서비스 연동 ④

그룹웨어 (GW CLI/Skill) 활용하기

`gw` 명령어로 결재함 읽기, 출근기록 대조, 근태 작성까지 손쉽게 처리합니다.

에이전트 요청 예시

"gw info 상태 확인하고, 내 결재함에서 미결건이 있는지 조회해줘."

출근 대조 요청 예시

"gw late-check로 지난 달 지각일과 기안된 지참 내역을 대조해줘."

gw 주요 명령어 모음

  • gw info : 세션 접속 상태 점검
  • gw approvals : 결재함 리스트 읽기
  • gw draft ... : 지참/연가 근태 기안전 작성
  • gw late-check : 출근기록 vs 지참 결재 대조
실습 3단계

나만의 Custom Skill 만들기

반복되는 업무는 SKILL.md 파일 하나로 포장하세요!

~/.claude/skills/my-briefing/SKILL.md
---
name: my-briefing
description: 아침 일과 시작 시 결재함과 메일을 한눈에 요약하는 스킬
---

# 모닝 브리핑 스킬

1. `gw approvals`를 실행하여 새로운 결재건 확인
2. `mail` 스킬로 읽지 않은 메일 수신함 확인
3. 결과를 종합하여 오늘 할 일 요약 출력

스킬 만드는 3단계

  1. 폴더 생성: ~/.claude/skills/스킬명/
  2. SKILL.md 작성: YAML Frontmatter (name, description) + 프롬프트 지침
  3. 에이전트에 테스트: "내 스킬 실행해줘" 입력!
