## 1부. 개념: 채팅창 vs 에이전트 (17:00–17:10, 10분)

### 핵심 메시지
> "채팅창은 AI가 **답을 말해주는 곳**, 에이전트는 AI가 **내 컴퓨터에서 직접 일하는 곳**"

1. **지금까지**: 질문 → 답 복사 → 붙여넣기 → 에러 → 다시 복사… AI는 내 파일과 화면을 볼 수 없음
2. **에이전트**: 내 폴더의 파일을 읽고, 고치고, 프로그램을 실행하고, 결과를 확인하고, 틀리면 스스로 재시도. 브라우저까지 조작 가능 (사례1이 바로 이것)
3. **비유**: 전화 상담 컨설턴트 vs 옆자리에서 직접 손 움직이는 동료
4. **안전장치**: 셋 다 파일 수정·명령 실행 전 **승인을 물어봄**. 허락 없이는 안 움직임
5. **단, 주의**: 중요한 폴더(진행 중인 보고서 폴더 등)에서는 실행하지 말 것. 실습은 빈 폴더에서
6. 도구 3종 비교표 (위 배정표 + 형태: Claude Code/Codex는 터미널, Antigravity는 VS Code 스타일 앱)
7. **핸드아웃 배포** ("핵심개념 핸드아웃" 별도 문서): "AI 신입사원" 비유표만 30초로 훑기 — CLI=대화 창구, MCP=사내 시스템 출입증, 스킬=업무 매뉴얼, 플러그인=세트 상자, AGENTS.md=팀 규칙 게시판. "자세한 건 핸드아웃에 다 있고, 오늘 시연에서 MCP와 스킬이 실제로 어떻게 쓰이는지 보실 겁니다" — 개념 강의는 여기까지, 나머지는 시연 중에 용어가 나올 때마다 비유로 되짚기 (예: 사례1에서 "지금 그룹웨어 출입증, 즉 MCP를 쓰는 겁니다")

## 3부. 설치 실습 (17:25–17:42, 17분)

거수로 구독 파악 → 3그룹으로 나눠 동시 진행. 진행자는 돌아다니며 지원.

### A. Antigravity (Gemini/무구독 그룹)
1. `antigravity.google/download` → OS에 맞게 다운로드 → 설치 실행
2. "Start fresh" 선택 → 에이전트 모드는 검토 중심(승인형) 권장
3. 구글 계정 로그인 → 채팅창에 "안녕이라고 대답해줘"로 동작 확인

### B. Claude Code (Claude 구독 그룹)
- Mac: 터미널에서 `curl -fsSL https://claude.ai/install.sh | bash`
- Windows PowerShell: `irm https://claude.ai/install.ps1 | iex`
- 설치 후 `claude` 입력 → 브라우저 열리면 Claude 계정 로그인

### C. Codex (ChatGPT 구독 그룹)
- Mac: `curl -fsSL https://chatgpt.com/codex/install.sh | sh`
- Windows PowerShell: `powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"`
- `codex` 입력 → "Sign in with ChatGPT" → 브라우저 로그인

### 트러블 즉답표
| 증상 | 대응 |
|---|---|
| "command not found" | 터미널 완전히 껐다 다시 열기 |
| Claude Code 로그인 거부 | 무료 플랜 → Antigravity 그룹으로 이동 |
| Windows에서 꼬임 | 오늘은 Antigravity로 전환, CLI는 추후 개별 지원 |
| 크게 뒤처지는 분 | 옆자리 완료자와 페어로 묶기, 전체 진행은 계속 |
