슬랙 · 그룹웨어 · 메일을 내 AI에 연결하고,
나만의 스킬(Skill)을 만드는 한 시간짜리 실습.

오늘의 목표

한 시간 뒤, 당신의 AI가
회사 도구를 직접 만진다

1 붙인다

Slack·그룹웨어·메일·먼데이를 내 AI(Claude Code / Codex)에 MCP·커넥터로 연결한다.

2 만든다

내 반복 업무 명령을 SKILL.md 한 장으로 나만의 스킬로 만든다.

3 나눈다

심링크·MCP 자동등록으로 팀에 플랫폼 안 가리고 배포한다.

오늘 쓰는 자산은 전부 우리 github(z0nam)에 공개/사내로 올라가 있습니다. 집에 가서도 그대로 따라 할 수 있게.

개념 ① · MCP

MCP = AI에 도구를
꽂는 표준 플러그

USB처럼, 규격을 한 번 맞추면 Claude·Codex·Gemini 어디서든 같은 도구가 꽂힙니다. AI는 그 도구를 "함수"처럼 직접 호출하죠.

붙는 길은 크게 두 가지 — 오늘 둘 다 해봅니다.

① 원격 커넥터 클릭

claude.ai에서 스위치만 켜면 됨. Slack · Gmail · 캘린더 · monday. Claude Code까지 자동 공유.

② 로컬 stdio 서버 명령

프로그램을 내 컴에서 돌리고 claude mcp add로 등록. 서버 하나가 4개 앱을 먹는다.

개념 ② · Skill

Skill = "이 도구 언제·어떻게 쓰나"
AI에게 주는 사용설명서

📄 SKILL.md 패턴

PATH에 셸 명령(CLI)을 깔고, 사용법을 적은 SKILL.md 한 장을 skills 폴더에 심링크. AI가 알아서 Bash로 부른다.

→ messages · contacts · gw · mail

🔌 MCP 서버 패턴

프로그램을 stdio로 감싸 claude mcp add로 등록. AI가 툴(함수)로 직접 호출. 인자·반환이 구조화됨.

→ korea-rio-mcp (messages도 가능)

가벼운 셸 명령 = 스킬 · 구조화된 함수·크로스플랫폼 = MCP. 오늘은 둘 다 손으로 만져봅니다.

사전 세팅 · 5분

준비물

  • Claude Code 또는 Codex CLI 설치 + 로그인 (AI 구독)
  • git · gh · node (없으면 실습 일부만)
  • ~/.local/bin 이 PATH에 있을 것 — 스킬 CLI가 여기 깔림
  • (맥) 실습별 권한: 터미널에 Full Disk Access 등
check-env.sh
# 작업 폴더 + 로컬 bin 준비
mkdir -p ~/dev ~/.local/bin

# PATH에 ~/.local/bin 있는지 확인
echo $PATH | tr ':' '\n' | grep -q "$HOME/.local/bin" \
  && echo "OK" || echo "PATH에 추가 필요"

없으면 ~/.zshrc에 export PATH="$HOME/.local/bin:$PATH" 한 줄.

실습 B · 그룹웨어사내 사례심화

레거시 그룹웨어도 AI가 만진다

그룹웨어를 CLI+어댑터로 감싸고 SKILL.md로 노출. MCP가 아니어도 됩니다. 우리 GW에 맞춰 어댑터만 갈면 다른 그룹웨어로 확장.

  • 결재 알림이 Slack DM으로 → 그룹웨어↔슬랙이 한 흐름
  • 상신 같은 위험 행위는 사람이 (기안 직전 정지)
  • 자격증명·내부망 IP는 화면 밖 — 오늘은 패턴만
gw · (사내) ji-gw-ai
gw approvals              # 결재함 읽기
gw download <wscNo> --dm  # 본문 → Slack DM
gw late-check --draft    # 출근대조→지참 기안
gw budget                 # 과제 예산 잔액

패턴 요지: 레거시 시스템 ← CLI/어댑터 ← SKILL.md. 웹만 있는 낡은 시스템도 이렇게 AI에 붙습니다.

실습 C · 메일z0nam/mail-skill심화

메일을 백엔드 중립으로 묶는다

엔진(Himalaya)을 어댑터 뒤에 숨긴 5-verb 계약. 엔진을 바꿔도 bin/mailskill 한 파일만 고치면 사용법은 그대로.

설치 개요
brew install himalaya age
~/dev/mail-skill/scripts/bootstrap.sh
# age키+심링크 → 계정 앱비번 등록
5-verb 계약
mailskill accounts
mailskill list   <acct> 10
mailskill search <acct> <query>
mailskill read   <acct> <id>
mailskill reply  <acct> <id> # 초안만

3갈래 라우팅: 주 Gmail은 커넥터, 그 외 IMAP은 어댑터, 과거메일은 로컬 Maildir. 시크릿은 age 암호화(평문 없음).

실습 D · MCP 서버모두맥 · 윈도우 공통

MCP 서버를 직접 꽂아본다

z0nam/korea-rio-mcp — 지역 경제파급효과를 계산하는 크로스플랫폼 MCP 서버. 서버 하나가 세 플랫폼을 먹습니다.

Claude Code
uv tool install git+https://github.com/\
z0nam/korea-rio-mcp

claude mcp add korea-rio \
  -- korea-rio-mcp
~/.codex/config.toml
[mcp_servers.korea_rio]
command = "korea-rio-mcp"
~/.gemini/settings.json
{ "mcpServers": {
  "korea-rio": {
    "command": "korea-rio-mcp" }}}

확인: claude mcp list → ✔ Connected. 그다음 "서귀포에 100억 투자하면 생산유발효과?"라고 물어보세요.

실습 E · 나만의 스킬라이브 데모 ★

SKILL.md 한 장 + 심링크 두 줄

.claude/skills/mytool/SKILL.md
---
name: mytool
description: 무슨 일을 하는지 + "언제
  이 스킬을 쓰는지" 트리거 문장.
  "OO 해줘" 같은 발화가 오면 먼저
  이 스킬을 본다.
---

# mytool
## 명령
mytool run <arg>  # 하는 일
## 안전수칙
쓰기·삭제는 사용자 승인 후.

본보기는 z0nam/messages-cli. 핵심은 frontmatter의 description — "언제 쓰는지"를 잘 써야 AI가 알아서 집어듭니다.

심링크 = SSOT (한 원본, 양쪽 공유)
# CLI를 PATH에
ln -sf "$PWD/mytool" ~/.local/bin/mytool
# SKILL.md 하나를 Claude+Codex 양쪽에
ln -sf "$PWD/.claude/skills/mytool" \
  ~/.claude/skills/mytool
ln -sf "$PWD/.claude/skills/mytool" \
  ~/.codex/skills/mytool

원본 한 곳만 고치면 Claude·Codex 양쪽에 반영. 이게 우리 도구들이 두 에이전트를 동시에 지원하는 비결.

팀에 나눌 땐 두 원칙

1 플랫폼 프리

AI 구독만 있으면 Claude·Codex·Gemini 동일하게. 로컬 stdio MCP 하나 = 데스크톱·CLI 넷을 한 번에 커버.

2 "설치 수준" UX

컴 잘 모르는 연구원도 프로그램 설치 한 번 경험으로. 등록은 setup 명령이 각 config에 멱등 주입.

🖥️ 개발자·데스크톱

로컬 stdio MCP + 심링크 SSOT 스킬.

💬 소비자 챗앱

ChatGPT·Gemini앱은 로컬 MCP 불가 → 자체호스팅 웹링크(HTTP)로 우회.
